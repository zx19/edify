## 4. 部署后验收（curl 冒烟）

约定：`BASE=https://qa-xai.xingshulin.com/lomva/console/api`（QA 子路径形态）；密码字段 = **明文密码的 base64**（与 e2e `encodeField` 同 ✅——若部署开了密码加密则需 RSA，QA 现状未开 ❌待部署时确认）。写请求要领：login 响应会 Set-Cookie 三个 token；**CSRF cookie（`__Host-csrf_token`，https 下带 `__Host-` 前缀 ✅ `libs/token.py:72-77`）的值必须作为 `X-CSRF-Token` 请求头回传**（admin 装饰器 auth→csrf→role 校验 ✅）。

```bash
BASE=https://qa-xai.xingshulin.com/lomva/console/api
JAR=/tmp/qa-admin-cookies.txt
PW_B64=$(printf '%s' '<founder-password>' | base64)

# A. setup 状态（QA 存量=finished；全新环境才见 not_started）
curl -s $BASE/setup   # → {"step":"finished", ...}（✅ 形状见 setup.py:33）

# B. login（无空间创始人也应 200——预检放行 ✅；QA 创始人有空间同样 200）
curl -s -c $JAR -X POST $BASE/login -H 'Content-Type: application/json' \
  -d "{\"email\":\"<founder-email>\",\"password\":\"$PW_B64\",\"remember_me\":true}"
# → {"result":"success"}

# C. profile 双字段（QA 改库后期望 install；env 名单账号期望 env）
curl -s -b $JAR $BASE/account/profile
# → {..., "is_system_admin": true, "system_admin_source": "install"}

CSRF=$(grep csrf_token $JAR | awk '{print $NF}')

# D. 建空间（owner=另一已注册 active 邮箱 → owner_pending=false）
curl -s -b $JAR -X POST $BASE/admin/workspaces \
  -H "X-CSRF-Token: $CSRF" -H 'Content-Type: application/json' \
  -d '{"name":"验收空间","owner_email":"<member-email>"}'
# → 201 {"id":..., "name":"验收空间", "owner_pending":false, "invite_url":null}

# D2. 建空间（owner 未注册 → PENDING 预创建 + 邀请链接）
curl -s -b $JAR -X POST $BASE/admin/workspaces \
  -H "X-CSRF-Token: $CSRF" -H 'Content-Type: application/json' \
  -d '{"name":"邀请验收","owner_email":"newbie@xingshulin.com"}'
# → 201 {"owner_pending":true, "invite_url":"/activate?token=..."}
#   QA 无 SMTP：邮件静默失败不阻塞，链接从响应取、手动转交 ✅（审计 detail 记 invite_mail_dispatched）

# E. 空间列表（含 owner/member_count）
curl -s -b $JAR "$BASE/admin/workspaces?keyword=验收"

# F. 名单授予/撤销（founder 独占；current_password 为 founder 明文密码）
curl -s -b $JAR -X POST $BASE/admin/system-admins \
  -H "X-CSRF-Token: $CSRF" -H 'Content-Type: application/json' \
  -d '{"email":"<member-email>","current_password":"<founder-password>"}'
# → 201（直授，source='grant'）
curl -s -b $JAR $BASE/admin/system-admins   # 名单含 install/grant 两行
curl -s -b $JAR -X DELETE $BASE/admin/system-admins/<account_id> \
  -H "X-CSRF-Token: $CSRF" -H 'Content-Type: application/json' \
  -d '{"current_password":"<founder-password>"}'

# G. 审计（应见 workspace.create/admin.grant/admin.revoke）
curl -s -b $JAR "$BASE/admin/audit-logs?limit=10"

# H. 负路径：普通成员账号 login 后调 admin 端点 → 403 ✅（装饰器单测锁定）
```

**清理**：D/E 验收空间可归档（`POST /admin/workspaces/<id>/archive`）；F 已撤销即净。
