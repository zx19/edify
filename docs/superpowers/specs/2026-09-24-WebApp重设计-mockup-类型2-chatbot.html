设计落点注记(对照 2026-09-24-WebApp重设计-design.md §4)

  • 无抽屉:嵌入式无会话历史(现状如此),会话管理不存在,方向 A 的抽屉不适用。
  • header 中性化:不再吃 chat_color_theme 蓝底(chat_color_theme_inverted 退役口径);accent 只注入交互件(发送钮/focus 环/建议 hover/设置卡 CTA)——工具条「accent 注入」可演示换色。
  • 聊天核心 = chat 族同语言:浅灰胶囊/无框回答/hover 操作条/折叠条族/悬浮输入卡,全部复用。
  • Powered by 落点沿用现状:桌面 header 右;气泡窗/移动 = 窗口或卡片底部。
  • 保留红线逐字保全:iframe 三消息协议(ready/config/expand-change)、embed.js 父页行为、URL 参数契约(sys.*/user.*/inputs 预填/locale/sendOnEnter/conversation_id)。展开/收起钮演示 = 协议条件(isToggledByButton && !isDraggable)。
  • 条件项演示:勾「URL 锁定会话」→ 重置钮消失;勾「变量表单」→ 欢迎屏出「聊天设置」卡(开始对话 CTA);勾掉「展开/收起钮」→ 气泡窗该钮消失。
  • 去 Dify 化:isDify() referrer 恒 false 分支删除(删旧台账);createTheme/CssTransform 样式串机制由 token + accent 注入替代。
  • hideProcessDetail:chatbot 隐藏工作流过程明细(现状语义保留);深度思考折叠条保留(QA 实证)。
