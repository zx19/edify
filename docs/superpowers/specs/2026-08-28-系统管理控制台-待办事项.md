## 一、插件管理页（`/admin/plugins`）

### 1.1 插件详情页
- **现状**：插件管理表格只有列表，点击行无详情
- **需求**：点击插件打开详情页/右侧抽屉，展示插件详细信息（描述、版本、类型、分发范围、操作等）

### 1.2 修改范围 UI
- **现状**：操作列有「改范围」按钮，但点击无交互
- **需求**：点击「改范围」弹出范围选择弹窗（全部空间 / 指定空间多选），与插件中心安装时的范围选择弹窗一致
