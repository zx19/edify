设计落点注记(对照 2026-09-24-WebApp重设计-design.md §5)

  • D7 单列化:废左右双列;表单在上、结果流内(替换式 = 最新一次)。
  • D8 segment:运行一次 / 批量运行* / 已保存*(*条件项:批量 = ui_config.components.show_batch_tab 默认隐;已保存 = completion 型专属,工具条切类型验证)。
  • D10:移动端结果流内,原底部抽屉 + drag handle 取消。
  • 运行钮:运行中原位变 ⏹ + spinner(同 D4 口径),结果区不再单独出停止钮。
  • 工作流过程卡:类型 4 专属,show_workflow_steps(既有列,非 ui_config)关闭时整卡不渲染;状态 badge 绿勾。
  • 隐藏变量:不在表单渲染(URL sys.*/默认值注入)——无可见 UI,仅注记。
  • 结果项:结果/详情双 tab(详情 = inputs + meta + 任务编号);保存/再来一条 = completion 专属;TTS 朗读条件显示。
  • ⋯ 菜单(header):主题三态/隐私政策/关于/退出登录——族内无抽屉,菜单落点 header。
  • 空态:结果区轻提示占位(替代现状 NoData 插图文案,功能行落点 = 轻量空态)。
