## ui_config 降级规则（新）

| 开关 | off 时 |
|---|---|
| `layout.show_conversation_sidebar` | **抽屉入口不渲染**（无 ☰/⌘K）；header 保留新建+重置+会话标题▾（操作不丢）；主题/关于等菜单项不可达（与现状 sidebar 隐藏即菜单不可达一致） |
| `layout.sidebar_width` | **退役**（D9；key 接收不报错、无渲染） |
| `components.show_message_actions` | 消息操作行整行不渲染（含赞踩/复制/重新生成/朗读/多答案切换/性能行） |
| `components.show_citation` | 引用折叠条及列表不渲染 |
| `components.show_suggested_questions` | 欢迎屏建议格 + 答案后推荐 pill 均不渲染 |
| `brand.footer_text` | 非空 → 抽屉底部品牌行直出该文本；空 → 走品牌链（工作区级→杏树林默认） |
