## 1. 背景与范围

**总原则（2026-08-31 用户确认）**：**保留原有功能、删减不用的、重新设计 UI**。删减依据有二：托管收窄（上游方案 A §6.4 收走的安装/凭据/权限能力）与 QA 现状实证（在用的保留，不用的删）。本稿的功能去留结论以 §2 末「功能去留总表」为准。

一期收窄后，普通用户工作台从「全功能自助空间」变为「纯使用方」：插件/凭据/成员治理收归系统管理控制台，工作台保留使用与编排。本 mockup 定义收窄后的工作台形态与信息架构。

**四条主线**（2026-09-03 由三条补为四条）：

1. **侧栏重构**：全局侧栏改为「logo + 空间切换器 + 导航（主页/工作室/Agents/知识库/Skills/集成/应用）+ 底部账号区」，视觉语言与系统管理控制台统一（白+黑+橙，`#FF8C00` 选中/强调）。
2. **集成页重构**（最大改动面）：导航删「Marketplace」一级入口；集成展开二级（模型供应商/工具），工具页内再分三级子 tab（工具插件/MCP/工作流作为工具/Swagger API）——四个子 tab 现状已存在于集成二级侧栏（QA 实证），此处为**视觉重排非新 IA**。
3. **空间侧全面只读化**：插件安装/升级/卸载/凭据配置/自动更新入口全部移除，对应四道 api 层防线（见总体方案 §6.4，含 `/permission/change` 锁改），UI 只做呈现收敛。
4. **其他功能保留并 UI 重构**：主页/工作室/Agents/Skills/知识库/MCP/工作流/Swagger 等保留功能**功能行为不变，但全部换成新视觉语言**（照 QA 结构重画，token/组件与系统管理控制台统一）——「保留」指能力与数据不动，不是界面原样保留。

**非目标（一期不做）**：工作室与主页改版（维持现状）、Agents/Skills 任何改动（保留现状）、知识库管线型（Pipeline）新建入口、**数据来源（整体不开放，含 OAuth 类与 Key 类）**、**触发器（一期不用）**、空间内插件安装/调试/权限页。

**导航删除项**（对照 QA 现状实证，2026-08-31 校准——现状一级为 主页/工作室/Agents/知识库/Skills/集成/Marketplace，无「探索」页）：**Marketplace 一级入口整页删除**（市场内容不再在空间侧出现，含工具页底部市场精选轮播）；集成二级的 数据来源/触发器/扩展/自定义端点 四个类型页**一期不出现**（**Agent 策略除外——2026-09-01 用户决策保留为集成二级，与工具同级**，见 §3.3.2a），连同 调试/权限 两个底部入口与顶部「安装」按钮——它们的空间侧入口随托管收窄移除，类型过滤在系统管理控制台插件管理页承载。

**Agents（BETA）/ Skills 保留说明（2026-08-31 用户确认）**：两者均属新 Agent 栈（Agent App/Agent v2 与能力包，QA 实证 Skills 卡片以"N 个 Agent"为副标题），**保留在导航、一期不改动**。与《agent-架构梳理与摘除评估》的关系：摘除是独立决策，若日后执行其方案 A（`NEXT_PUBLIC_ENABLE_AGENT_V2=false` 隐藏入口），本设计无需返工——届时 nav 项随 flag 消失即可。mockup 已照 QA 补齐两页列表结构（2026-09-01）：**Agents**=筛选 pill（全部/已发布 n/草稿 n）+ 按名称搜索 +「我创建的」+ 排序方式 + 创建下拉（创建空白应用/导入 DSL 文件，无模板项）+ 空态「暂无 Agent」；**Skills**=标签筛选 + 按名称或描述搜索 + 导入（**系统文件选择器直开**，无自定义弹窗）+ 创建（跳 SKILL.md 编辑页：左文件树 + 中指令编辑 + 右 Skill Builder 对话面板 + 底部 Draft/发布栏——编辑器不展开）+ 卡片（DRAFT 徽标/图标/名称/描述/添加标签/「N 个 Agent · 编辑时间」）。

**空间切换面板**（侧栏顶部触发，上滑面板）：**操作行两项——工作空间设置（打开既有 `?settings=` 弹窗）、邀请成员**（QA 实证现状切换器菜单含此两项，owner/admin 视角的成员管理入口，属保留功能）；当前空间高亮 + 角色副文本；列表含多空间、**已归档空间置灰不可选**（`ws-prole=已归档` + `opacity:.5`）；无「创建空间」入口（`ALLOW_CREATE_WORKSPACE=false`，创建收归系统管理员）。角色文案口径：owner/admin/editor/normal 直显；`dataset_operator` 显示为「知识库专员」（受 `dataset_operator_enabled` feature 控制开放）。

**头像下拉菜单**：账号区四项——个人资料（→`/account`）、密码与安全（→`/account`）、**偏好设置**（→`?settings=preferences`，语言/时区）、**外观**（主题切换）——后两项为 QA 现状功能、用户确认保留（2026-08-31）；退出登录。系统管理员账号在同菜单**追加**「系统管理」入口（`is_system_admin` 显隐，跳 `/admin`）——mockup 已补画（带"仅系统管理员可见"标注）。

**应用（原 WEB APPS 区重设计，2026-09-03 终版；QA 实证为现有功能，非新增）**：**一级导航项**（居导航末位、与主导航连续——无分隔线、无内嵌条目、无徽标；初稿「可折叠分组 + 计数徽标 + 内嵌条目 + 查看全部」经两轮简化定稿），点击直达 **`/apps` 应用列表页**：搜索 + 卡片网格 + 按最近使用排序，点击卡片进 `/installed/<id>` 内嵌使用页（聊天/表单 UI）。**与工作室的分工**：工作室 = 编辑门（全量应用、builder，卡片信号「编辑于」）；应用 = 使用门（已安装子集、member，卡片信号「最近使用」、无编辑入口）——数据同源（installed ⊆ 工作室应用）但人群与动作正交。数据源与行为维持现状（mockup 的"会议纪要"即 QA 真实条目），仅视觉与入口重构——原「WEB APPS」英文大写标签小节作废。

**集成分组交互（2026-09-03 补）**：子级三入口（模型供应商/工具/Agent 策略）**默认收起**，点击「集成」一级项切换收起/展开——展开且当前不在集成视图时同时进入默认子页，收起时页面不动；**展开态独立于当前视图并记忆用户选择**（localStorage），不随跳转强制展开或收起（mockup 原为子级常驻展开，实现按此修正）。

## 3. 页面设计

### 3.1 主页 / 工作室

一期**功能不改动**：主页（最近 + 模板）、工作室维持现状。mockup 已照 QA 结构重画（2026-09-01）：

- **工作室工具栏**：类型 / 标签 / 创建者 / 排序方式（最近修改）四个筛选下拉 + 搜索 + 右侧「{ } Snippets」与「＋创建」下拉（创建空白应用 / 从应用模板创建 / 导入 DSL 文件）。筛选下拉选项照 QA（2026-09-01 实证）：类型=单选（全部/工作流/Chatflow/聊天助手/Agent/文本生成应用）；标签=搜索或者创建 + 空态「没有标签」+ 管理标签；创建者=成员多选（含「你」标记）；排序=单选（最近修改/最近创建/最早创建）。
- **应用卡片**：图标（含类型角标）+ 名称 + 类型 + （部分应用含简介）+ 「＋ 添加标签」虚线 chip + 编辑者与完整编辑时间（`YYYY/MM/DD HH:mm`）。
- 页面底部：「拖放 DSL 文件到此处创建应用」提示。

### 3.2 知识库（收窄）

- 保留：创建即用型（General）知识库、本地文件上传 / 网址抓取两导入源、标签筛选与搜索。
- 删除：**数据源同步导入整体不开放**（2026-08-31 用户决策：含 OAuth 类 Notion/网盘与 Key 类腾讯云 COS，不单拆 OAuth）——顶部 `notice-blue` 提示「导入源仅保留导入已有文本；数据源同步一期暂不开放」。⚠️ 文案**不提**「收归系统管理员配置」：组织代授权是二期能力，管理员一期也配不了，指路即误导（QA 实证：已装 Notion/COS/GitHub 三个数据源插件均未配置，无实际使用）。
- ⚠️ 边界：**管线型（Pipeline）知识库卡片**（mockup 里有 `Pipeline` 类型卡片）是刻意保留的存量展示口径--已有管线型库仍可见可进，**新建入口一期隐藏**。实现时若存量库为零，该类型卡片自然不出现，无需特判。存量 pipeline 内的数据源节点因无可用数据源插件，显示插件缺失态（点发现口径，同 §3.3.4）。

### 3.3 集成（重构主体）

**二级导航 + 三级子 tab 的双层结构**：侧栏二级（模型供应商/工具）承载大类切换；工具页内三级子 tab（pill 式，深色选中）承载工具四形态。这个双层是**刻意设计**：模型供应商与工具的差异是「有无凭据语义」，工具插件/MCP/工作流/API 的差异是「托管 vs 空间自建」--两级切分让每一层只表达一个维度。

#### 3.3.1 模型供应商（模型清单纯查看 + 默认模型设置保留，2026-08-31 二次修订）

- **模型清单与凭据的配置收归系统管理控制台**：无 Add API Key、无添加模型、无安装入口、无自动更新。注意这比 Dify 现状收得更窄——现状供应商页有 添加模型（QA 实证），用户确认（2026-08-31）收走，空间侧只回答"有哪些供应商、哪些模型可用"。
- **默认模型设置保留**（2026-08-31 用户确认）：入口在**页面最外层**（工具栏右侧，不进入任何供应商抽屉/卡片），空间级语义与 Dify 现状一致。弹窗结构照 QA（2026-09-01 实证）：居中模态，副文案"当未配置特定模型时，设置整个工作空间默认使用的模型"，五个类型下拉（系统推理模型/Embedding/Rerank/语音转文本/文本转语音，已选显示模型名、未选显示"模型设置"占位）+ 取消/保存。
- 卡片网格照 QA 现状结构：图标 / 名称 / **版本号**（mono）/ **模型类型徽标**（LLM·TEXT EMBEDDING 等 pill）/ 状态徽标。点击卡片开**右侧抽屉**（与工具抽屉共用外壳）：模型清单按类型分组（LLM/Embedding/Rerank/TTS…），mono 字体列表，**纯查看无任何操作按钮**。
- 状态两态：可用（绿）/ 未配置（灰）。「未配置」卡片标注"未配置凭据，模型不可用"，抽屉内 amber 提示"如需使用请联系系统管理员配置"——这是显式分派解耦后的正常态（插件已装、组织未配凭据），**不是错误态**。
- **治理叙事不呈现**：页头无托管徽标、卡片无"已由组织统一配置"类小字（见 §4「治理叙事原则」）。
- ⚠️ mockup 不含「配额不足」琥珀态；一期实际状态仅 可用/未配置 两态，配额/凭据失效等细分态二期再分层。

#### 3.3.2 工具插件（卡片 + 只读详情抽屉）

| 触发器存量（QA 已装 GitHub trigger 1.5.0） | 一期不用触发器：不分发、nav 无入口；存量建议由系统管理员在插件管理页**移除·从所有空间卸载**（卸载波，连带删凭据；2026-09-01 起用词，存量无托管记录需先经安装流收编），不移除则插件留在空间但无任何 UI 入口 |

## 5. 实现注意点与要求

1. **视觉 token 全量对齐系统管理控制台**：CSS 变量集（`--bg/--text-1/--accent` 等）两份 mockup 完全一致，实现时抽公共 token 层（Tailwind v4 + `@langgenius/dify-ui` primitives），不允许两套控制台各写一套色值。
2. **侧栏是共享组件**：本 mockup 的侧栏与系统管理控制台的侧栏是**同一个组件的两个实例**（同一账号区/同一视觉/不同导航集）。实现为共享组件目录（如 `web/app/components/console-shell/`），供 `(commonLayout)` 与 `/admin` 独立 layout 两处引用——**不要放进任一路由组目录**（admin 不挂 commonLayout，放 `(commonLayout)/` 下名不正言不顺），也不要复制两份。
3. **空间切换器**：mockup 的 `ws-panel` 为静态演示；实现对接既有 `currentWorkspaceAtom` 与租户切换 API，切换成功后 `location.assign()` 整页刷新（QA 现状即如此，沿用）。**归档空间置灰但可见**（切换后 login 预检会拦，UI 提前置灰防误触）；「创建空间」入口按 `ALLOW_CREATE_WORKSPACE=false` 不渲染；**「工作空间设置」「邀请成员」两操作行保留**（现状功能，分别打开 `?settings=` 弹窗与邀请弹窗，邀请成员按 owner/admin 角色显隐）。
4. **头像菜单的「系统管理」入口**：mockup 已补画。实现必须包含——`is_system_admin` 由 `/account/profile` 下发，真则追加菜单项（普通用户菜单里完全没有该项，无任何标注），点击跳 `/admin`。这是两份控制台之间的唯一互跳通道，漏掉会造成系统管理员必须手敲 URL。菜单其余项（个人资料/密码与安全/偏好设置/外观/退出登录）均为现状功能保留，分别对接 `/account` 页与 `?settings=preferences`、主题切换。
5. **工具详情抽屉的数据源**：卡片与抽屉数据来自 daemon `list_plugins`（经 api 聚合）；actions 列表来自插件 declaration。「内置」工具（非插件）走 `BuiltinToolProvider` 既有链路，混排时以「有无 plugin_unique_identifier」判型。
6. **登录失败态的路由归属**：不属于 `/admin` 也不属于工作台路由组，实现为登录流程的终态页（login 组件内分支），不建独立 route。
7. **三级子 tab 的路由化**：`tools-builtin/tools-mcp/tools-workflow/tools-api` 实现为 `/integrations` 下的 query 或嵌套路由（浏览器前进后退可用），不用纯前端 state（mockup 是演示切换，真实页面要可分享 URL）。
8. **知识库 notice 文案**：指向「联系系统管理员」，不指向具体管理页 URL（普通用户无权访问 `/admin`，指路即死链）。
9. **一期验收联动**：本页「插件全部托管徽标/无安装入口」的验收与 UI 设计稿 §7 流 B QA 是同一套用例（`/integrations` 侧走查），两份文档共用 QA 清单，不重复立项。
10. **应用导航项与 `/apps` 页实现**（2026-09-03 终版）：复用现状已安装 WebApp 列表的数据源与行为（卡片 → `/installed/<id>`），只换视觉与入口——「应用」一级导航项 + `/apps` 列表页（搜索 + 卡片网格 + 最近使用排序）；无内嵌条目、无折叠态、无徽标。
11. **`?settings=` 弹窗存续**：弹窗体系整体保留（成员/偏好设置/品牌自定义等）；仅收敛其中的集成 modal 双入口（`integrations/modal.tsx` + `section-renderer.tsx` 的 modal 形态下线，只留 `/integrations` 页形态），注意该 modal 组件与页形态共享 renderer，下线时勿误伤页形态。
