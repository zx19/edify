创建工作空间

空间创建后，指定邮箱将成为该空间的 Owner。
若该邮箱尚未注册，将预创建账号并标记为「待激活」，通过邀请链接完成激活。

授予系统管理员

仅可授予已注册且已激活的账号。该操作会写入审计日志。
高危操作需要验证本人身份。

编辑凭据

组织级凭据仅保存服务端、全程掩码；空间自有凭据优先，未配置的空间回退使用组织凭据。
保存后仅以脱敏形式展示（sk-…****），任何人不可再读取明文。
插件分发范围：全部空间（在「插件管理」中调整）
凭据范围只能是插件分发范围的子集。
切换策略不会删除空间已有凭据，仅切换生效来源。
