# text-gen 族（completion/workflow）呈现层回炉 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 2026-09-24 重设计定稿（design §5：D7 分视图双列 + D8 segment + D10 移动流内）回炉 web-new text-generation 族呈现层——左侧栏拆解（app 信息上 header、tab 上移 segment、描述并入关于、品牌沉壳底），「运行一次」桌面双列（左表单 360 独立滚动/右结果自适应），批量/已保存单列 720，移动端单列。

**Architecture:** 呈现层 DOM/样式重排；hooks（`use-text-generation-app-state`/`use-text-generation-batch`/`result/hooks`）、服务层、契约（isInstalledApp/isWorkflow props、access-mode 门禁、保存 API）不动。视觉源 = `docs/superpowers/specs/2026-09-24-WebApp重设计-mockup-类型34-text-generation.html`；核销源 = `2026-09-24-WebApp重设计-功能对照表-类型34-text-generation.md`。结果项（`app/text-generate/item`）与已保存列表（`app/text-generate/saved-items`）为 console 共享面/已 token 化，**本单元零改动**（只换挂载位置）。

**Tech Stack:** React 19 + Tailwind 4（容器查询 `@[900px]:`）+ `@xsl/lomva-ui` 原语 + Vitest（`npx vp test --project unit`）+ i18next（`share.json`）。

## Global Constraints

- **旧轨 `web/` 零改动**；全部改动在 `web-new/`。
- **契约层不动**：`useTextGenerationAppState`/`useTextGenerationBatch`/`useResultRunState`/`useResultSender` 字段语义、`TextGeneration` 组件 props（`isInstalledApp`/`isWorkflow`）、`Res`（result/index.tsx）prop 签名、保存/收藏 API、批量执行机制（并发/聚合）——契约层 spec 必须不改仍绿。
- 三路由（`/completion` `/workflow` `/env/workflow`）+ `explore/installed-app` 嵌入面共用本组件——**同族携带**：类型 5（env-workflow）随之换颜（QA 清单缺口仍挂，见风险表）。
- i18n：只维护 `web-new/i18n/zh-Hans/share.json` + `en-US/share.json`（C14）。
- 视觉消费 `var(--*)` token；dark 走 `[data-theme='dark']` 自动反色，**不写 dark: 变体**；不写硬编码 hex。
- 家族根自挂 `.webapp-theme`（现状 index.tsx 已有，保留）；accent 注入 `buildAccentStyle(siteInfo?.chat_color_theme)` 保留。
- 每任务收尾：`cd web-new && npx vp test --project unit <触及 spec>` 绿 + `pnpm type-check` 0 + commit（`refactor(前端重写): …`，无 Co-Authored-By）。
- 选择器：role + accessible name；新容器 testid 登记文末表。
- 族 spec 基线：index 224 / sidebar 279 / menu-dropdown 260 / result-panel 200 / info-modal 56 行；族全量本地可跑，全仓 CI。
- **形态判别**：本族无 iframe 红线；桌面/嵌入窄容器退化用**容器查询**（`@container` + `@[900px]:`）而非视口媒体查询——installed-app 嵌在宽视口窄容器里，媒体查询会误判（对照表 §1：双列 <900px 退化单列）。
