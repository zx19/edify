**Goal:** 落地系统管理员体系与组织级管理后端：`is_system_admin` 双列判定、install 瘦身（只建管理员不建空间）、无空间管理员登录放行（load_user + login 预检双闸）、`/console/api/admin/*` 端点组（空间/成员只读/系统管理员两级名单/审计）、审计埋点、profile 下发管理员标记。

**Tech Stack:** Flask + Flask-RESTX（console_ns）、SQLAlchemy 2.x、Alembic（Flask-Migrate）、pytest。后端命令一律 `uv run --project api <command>`。集成测试 CI-only，本计划用单测 + curl 手工验证。

## Global Constraints

- 后端命令前缀：`uv run --project api`（仓库约定）。
- 提交信息精简、无 Co-Authored-By（用户规范）。
- 系统管理员可无空间：`/admin/*` 端点**不得**使用 `current_account_with_tenant()`（它会 assert tenant，无空间即 500），用 Flask-Login `current_user`。
- 高危约束（PRD US-4）：授予/撤销/转让/名单写操作**仅创始人**（`founder_admin_required`）；创始人不可自撤；写操作需当前账号密码确认；env 来源条目控制台不可撤；全部写审计。
- 两级语义：创始人 = `is_system_admin=true AND system_admin_source='install'`，全部署恒一位；转让是唯一身份让渡路径（原 founder 变 grant）。
- 枚举命名：审计 action 用点分小写（`workspace.create`、`admin.grant`、`admin.transfer`…）。
- 迁移**手写**（本地无 DB 连接，`flask db revision --autogenerate` 不可用；仿 `2026_08_25_1200-9b7c6d5e4f3a_add_normalized_email_to_accounts.py` 格式）。当前 alembic head = `5578e028b2f2`（Task 1 迁移的 down_revision；Task 3 迁移接 Task 1）。
- 模型层惯例：`models/` 下新模型用 `TypeBase`（MappedAsDataclass）——所有列必须带 `Mapped[...]` 注解（无注解不映射），注意 dataclass 字段顺序（无默认值字段不能跟在有默认值字段后，`init=False` 例外）；新模型须在 `api/models/__init__.py` 注册 import。
- 范围外（不在本计划）：`/api/env/*` 环境部署后端（env-workflow 走查卡点属另一项后端工作，另行立项）；插件托管/组织凭据（Plan C/D）。
- 运维注记（PRD US-4 AC5，非代码）：QA 已跑过旧形态 /install，上线时改库标记 source=install 或清数据重跑；生产全新部署由 /install 置位创始人。

```python
"""系统管理员判定：持久化标记 ∪ env 名单（大小写不敏感）；创始人 = source=install（全部署恒一位）。"""

from configs import dify_config
from models.account import Account


def _env_hit(account: Account) -> bool:
    emails = {e.lower() for e in (dify_config.SYSTEM_ADMIN_EMAILS or [])}
    return bool(account.email) and account.email.lower() in emails


def is_system_admin(account: Account) -> bool:
    if getattr(account, "is_system_admin", False):
        return True
    return _env_hit(account)


def get_system_admin_source(account: Account) -> str | None:
    """'install'|'grant'|'invite'（持久化列）；仅 env 命中时 'env'；非管理员 None。"""
    if getattr(account, "is_system_admin", False):
        return account.system_admin_source
    return "env" if _env_hit(account) else None


def is_founder_admin(account: Account) -> bool:
    return getattr(account, "is_system_admin", False) and account.system_admin_source == "install"
```

```python
from functools import wraps  # 已有则复用
from typing import Any, Callable  # 按文件现状

from flask_login import current_user
from werkzeug.exceptions import Forbidden, Unauthorized

from services.system_admin_service import is_founder_admin, is_system_admin


def system_admin_required[**P, R](view: Callable[P, R]) -> Callable[P, R]:
    """系统管理员（人）会话校验。与机器通道 admin_required（ADMIN_API_KEY）并存。

    注意：不得改用 current_account_with_tenant()——系统管理员可能无空间。
    """
    @wraps(view)
    def decorated(*args: P.args, **kwargs: P.kwargs) -> R:
        if not current_user.is_authenticated:
            raise Unauthorized("Login required.")
        if not is_system_admin(current_user):
            raise Forbidden("System admin only.")
        return view(*args, **kwargs)

    return decorated


def founder_admin_required[**P, R](view: Callable[P, R]) -> Callable[P, R]:
    """创始人管理员校验（两级模型：名单授予/撤销/转让独占）。普通系统管理员 403 兜底。"""
    @wraps(view)
    def decorated(*args: P.args, **kwargs: P.kwargs) -> R:
        if not current_user.is_authenticated:
            raise Unauthorized("Login required.")
        if not is_founder_admin(current_user):
            raise Forbidden("Founder admin only.")
        return view(*args, **kwargs)

    return decorated
```

```python
import sqlalchemy as sa
from sqlalchemy import DateTime, String, func
from sqlalchemy.orm import Mapped, mapped_column

from models.base import TypeBase
from models.types import LongText, StringUUID


class AdminAuditLog(TypeBase):
    __tablename__ = "admin_audit_logs"
    __table_args__ = (
        sa.PrimaryKeyConstraint("id", name="admin_audit_log_pkey"),
        sa.Index("admin_audit_logs_workspace_idx", "workspace_id"),
        sa.Index("admin_audit_logs_action_idx", "action"),
        sa.Index("admin_audit_logs_created_idx", "created_at"),
    )

    id: Mapped[str] = mapped_column(StringUUID, primary_key=True)  # default 由 service 显式赋 uuid4
    actor_account_id: Mapped[str] = mapped_column(StringUUID)
    action: Mapped[str] = mapped_column(String(64))
    target_type: Mapped[str | None] = mapped_column(String(32), default=None)
    target_id: Mapped[str | None] = mapped_column(String(64), default=None)
    workspace_id: Mapped[str | None] = mapped_column(StringUUID, default=None)
    detail: Mapped[str | None] = mapped_column(LongText, default=None)  # JSON 字符串
    created_at: Mapped[datetime] = mapped_column(
        DateTime, server_default=func.current_timestamp(), nullable=False, init=False
    )
```

> 注意 dataclass 字段顺序：`id/actor_account_id/action`（无默认）必须排在带默认值的字段前；`created_at` 用 `init=False`。类型注解按 `models/account.py` 惯例（`from datetime import datetime`）。

```python
import json
import uuid

from sqlalchemy.orm import Session

from models.admin_audit import AdminAuditLog


def audit_log(
    action: str,
    actor_account_id: str,
    target_type: str | None = None,
    target_id: str | None = None,
    workspace_id: str | None = None,
    detail: dict | None = None,
    *,
    session: Session,
) -> None:
    """系统管理操作审计。调用方负责 commit。"""
    session.add(AdminAuditLog(

        actor_account_id=actor_account_id,
        action=action,
        target_type=target_type,
        target_id=target_id,
        workspace_id=workspace_id,
        detail=json.dumps(detail or {}, ensure_ascii=False),
    ))
```

- 激活（公开）：token 校验（redis `system_admin_invite:token:{token}`，TTL 常量 `SYSTEM_ADMIN_INVITE_EXPIRY_HOURS = 72`）；成功 → 设 name/password（`libs.password.hash_password`）/status=active/initialized_at，token 作废；token 无效或已激活 → 400。
