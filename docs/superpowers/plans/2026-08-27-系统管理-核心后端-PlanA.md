# 系统管理控制台 · Plan A：核心后端实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地系统管理员体系与组织级管理后端：`is_system_admin` 判定、install 瘦身（只建管理员不建空间）、无空间管理员登录放行、`/console/api/admin/*` 端点组（空间/成员/系统管理员/审计）、审计埋点。

**Architecture:** 纯新增为主——新表 `admin_audit_logs` + `accounts.is_system_admin` 列；新控制器目录 `api/controllers/console/admin_console/`（避免与既有 `console/admin.py` 机器通道混淆）；业务逻辑复用 `TenantService`/`RegisterService`。不动现有 RBAC/权限链路。

**Tech Stack:** Flask + Flask-RESTX（console_ns）、SQLAlchemy 2.x、Alembic（Flask-Migrate）、pytest。后端命令一律 `uv run --project api <cmd>`。集成测试 CI-only，本计划用单测 + curl 手工验证。

## Global Constraints

- 后端命令前缀：`uv run --project api`（仓库约定）。
- 提交信息精简、无 Co-Authored-By（用户规范）。
- 系统管理员可无空间：`/admin/*` 端点**不得**使用 `current_account_with_tenant()`（它会要求 tenant），用 Flask-Login `current_user`。
- 高危约束（PRD US-4）：授予对象必须已注册且 active；最后一位系统管理员不可撤销；授予/撤销需当前账号密码确认；全部写审计。
- 枚举命名：审计 action 用点分小写（`workspace.create`、`member.remove`…）。

```python
from functools import wraps
from typing import Any, Callable

from flask_login import current_user
from werkzeug.exceptions import Forbidden, Unauthorized

from services.system_admin_service import is_system_admin


def system_admin_required[**P, R](view: Callable[P, R]) -> Callable[P, R]:
    """系统管理员（人）会话校验。与机器通道 admin_required（ADMIN_API_KEY）并存。

    注意：不得改用 current_account_with_tenant()——系统管理员可能无空间。
    """
    @wraps(view)
    def decorated(*args: P.args, **kwargs: P.kwargs) -> R:
        if not current_user.is_authenticated:
            raise Unauthorized("Login required.")
        if not is_system_admin(current_user):
            raise Forbidden("System admin only.")
        return view(*args, **kwargs)

    return decorated
```

def audit_log(
    action: str,
    actor_account_id: str,
    target_type: str | None = None,
    target_id: str | None = None,
    workspace_id: str | None = None,
    detail: dict | None = None,

        workspace_id=workspace_id,
        detail=json.dumps(detail or {}, ensure_ascii=False),
    ))

```python
from flask_login import current_user
from flask_restx import Resource, reqparse
from werkzeug.exceptions import Forbidden

from controllers.console import console_ns
from controllers.console.admin import system_admin_required
from extensions.ext_database import db
from libs.password import compare_password
from models.account import Account, AccountStatus
from services.account_service import AccountService, TenantService
from services.audit_service import audit_log
from services.system_admin_service import is_system_admin
from sqlalchemy import select


class AccountNotFoundForGrantError(ValueError):
    pass


@console_ns.route("/admin/system-admins")
class SystemAdminListApi(Resource):
    @system_admin_required
    def get(self):
        with db.session() as session:
            accounts = session.scalars(select(Account).where(Account.is_system_admin == True)).all()  # noqa: E712
            return {"data": [{"id": a.id, "email": a.email, "name": a.name, "source": "grant"} for a in accounts]}

    @system_admin_required
    def post(self):
        parser = reqparse.RequestParser()
        parser.add_argument("email", required=True)
        parser.add_argument("current_password", required=True)
        args = parser.parse_args()

        # 本人密码确认（QA 无邮件服务，以密码确认替代验证码）
        if not compare_password(args["current_password"], current_user.password, current_user.password_salt):
            raise Forbidden("Password confirmation failed.")

        with db.session() as session:
            target = AccountService.get_account_by_email_with_case_fallback(args["email"], session=session)
            if not target or target.status != AccountStatus.ACTIVE:
                raise AccountNotFoundForGrantError("仅可授予已注册且已激活的账号")
            target.is_system_admin = True
            audit_log("system_admin.grant", current_user.id, target_type="account",
                      target_id=target.id, detail={"email": target.email}, session=session)
            session.commit()
            return {"id": target.id, "email": target.email}, 201


@console_ns.route("/admin/system-admins/<string:account_id>")
class SystemAdminItemApi(Resource):
    @system_admin_required
    def delete(self, account_id: str):
        parser = reqparse.RequestParser()
        parser.add_argument("current_password", required=True)
        args = parser.parse_args()
        if not compare_password(args["current_password"], current_user.password, current_user.password_salt):
            raise Forbidden("Password confirmation failed.")

        with db.session() as session:
            admins = session.scalars(select(Account).where(Account.is_system_admin == True)).all()  # noqa: E712
            if len(admins) <= 1 and admins[0].id == account_id:
                raise Forbidden("最后一位系统管理员不可撤销")
            target = session.get(Account, account_id)
            if target:
                target.is_system_admin = False
                audit_log("system_admin.revoke", current_user.id, target_type="account",
                          target_id=target.id, detail={"email": target.email}, session=session)
                session.commit()
            return {"result": "success"}, 200
```
