# M2 e2e 基线冻结 实施计划

> **定位**：前端重写 v2 计划 §7 M2 里程碑的执行计划（2026-10-08 立项）。前置已清：后端 T 系列全落地（T3 install 瘦身 + e2e 安装适配 ✅、CI 57 场景 650 步 + WebKit 4/4 实证绿 ✅、CI runner Depot→GitHub 托管修复 ✅）。
> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development。

**Goal**：WebApp 运行时旅程补齐（chat/chatbot/completion 三类型）+ e2e 双轨串行 harness + 全量双轨绿后冻结基线。

**成功标准（机器信号，与 v2 §7 M2 行对齐）**：

> 「冻结」语义注记（2026-10-08 与用户确认）：冻的是**判定规则**（双轨契约 diff = 0）与**起点证据**（当下功能全集的双轨全绿 trace）；场景清单是活的——新增/删减/降级走 matrix 登记通道并随里程碑重冻。基线管契约层，不管视觉/性能（另轨）。
1. `pnpm -C e2e e2e:full` 双轨（:3000 旧轨 + :3001 新轨）串行全绿——既有 57+4 场景 + 新增 WebApp 旅程；同 scenario 两轨 pass/fail 对齐（契约层 diff = 0）
2. trace 入库：`web/baselines/e2e-trace-<date>.json`（场景清单 + 双轨结果 + commit SHA）
3. v2 计划 §7 M2 行标 ✅

**范围外**：env-workflow 旅程（env 后端 `/api/env/*` 另立项）；控制台旅程双轨（3b 迁移后才有双轨对照意义，M2 只冻 WebApp 面——既有 console 旅程双轨跑但 diff 豁免登记）；iframe 气泡通信（chatbot embed 协议，单测已锁）；LLM 真实模型接入（无密钥依赖是硬约束）。

## 关键决策（已拍板口径见各任务注记）

1. **LLM 依赖 = OpenAI 兼容 stub**：e2e 后端不碰真实模型——本地起极简 stub（`POST /v1/chat/completions`，SSE/非流式双形态，echo 式固定应答），seed 经 console API 配 OpenAI-API-compatible provider 指向它。确定性、离线、秒级。❌待实证：provider 配置的 console API 精确端点（T1 侦察）。
2. **双轨 harness = E2E_WEB_TRACK 环境开关 + 双遍 runner**：`setup.ts` 加 web-new build/serve（:3001，build stamp 机制复用 webDir 同款）；run-cucumber 加 `--dual`：轨1（:3000）→ reset+seed → 轨2（:3001）→ scenario 级 pass/fail 对齐 diff 报告。
3. **step 分叉机制**：feature 文件两轨共用；step definitions 经 `E2E_TRACK` 环境变量解析轨感知选择器——新轨优先用 `web/baselines/*-unit-testids.json`（chat/chatbot/completion 三份已冻结 ✅）的 data-testid，旧轨用既有语义选择器。
4. **chatbot 旅程直开 `/chatbot/<token>` 页面**（不经 iframe 宿主页）；chat 旅程 app 类型用 basic chatbot（`/chat` 路由兼容 chat/advanced-chat/agent-chat，`getAppSiteURL` 已证实）；completion 用 text-generator app。

## Global Constraints

- 旧轨只读铁律：`web/` 零业务提交；e2e 新代码不得 import web/ 的东西（baselines/*.json 只读消费 ✅）。
- 每遍跑前 reset+seed（防前遍数据污染）✅ 现成机制。
- 后端命令 `uv run --project api`；e2e 命令 `pnpm -C e2e`；提交无 Co-Authored-By。
- CI 时长预算：web-e2e timeout 120min——双遍+新旅程估 ≤70min（单遍实证 13.5min），超限即拆分 job。
- 旅程断言只锁**契约层**（请求序列/结果渲染/会话落库），不锁呈现层像素（mockup 视觉另轨）。

## 风险

| 风险 | 对策 |
|---|---|
| provider 配置端点契约不存在/形态意外 | T1 先侦察再动手；契约缺失则读控制器直调或走管理 API |
| CI 双轨超时 | 单遍 13.5min 实证；双遍预算 70min，超时拆 job |
| 旧轨 WebApp 页面选择器脆（Dify 原 UI 无语义 testid） | 旧轨断言用 role/text 语义选择器；脆点登记不硬修（旧轨只读铁律） |
| web-new CI build 时长 | build stamp 缓存复用；首次冷建接受 |
